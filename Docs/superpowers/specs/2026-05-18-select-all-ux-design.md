# Select All UX Design

**Date:** 2026-05-18

**Problem**

当前结果表的 `全选` 体验不够顺手：
- `部分选中` 状态下点击复选框不会稳定切换到全选
- 文案没有展示当前已选数量，反馈较弱
- 全量切换使用整表重置，容易造成闪动和状态感知不佳

**Goals**

- 让 `全选` 在三种状态下都符合直觉
- 让用户一眼看到 `已选/总数`
- 保持现有布局，不引入额外按钮组
- 优化批量勾选实现，避免不必要的整表重置

**Non-Goals**

- 不新增 `反选` 按钮
- 不调整主表列结构
- 不修改计算、导出、备份逻辑

**Interaction Design**

- `未选中` -> 点击后 `全部选中`
- `部分选中` -> 点击后 `全部选中`
- `全部选中` -> 点击后 `全部取消`
- 无数据时控件禁用，并显示 `全选（0/0）`

**Feedback Design**

- 复选框文本动态显示为 `全选（已选/总数）`
- Tooltip 根据当前状态展示下一步动作：
  - 无数据：`当前没有可选择的项目`
  - 未选中或部分选中：`点击全选全部项目`
  - 全部选中：`点击取消全部选择`

**Implementation Approach**

- 在 `views/main_window.py` 中引入一个小型自定义复选框，重写 `nextCheckState()`，保证 `部分选中` 点击时统一进入 `全部选中`
- 在 `viewmodels/main_viewmodel.py` 中增加批量勾选 helper，用范围 `dataChanged` 替代整表 `beginResetModel()/endResetModel()`
- 在主窗口中集中刷新 `全选` 控件的 `文本 / tooltip / tristate / enabled` 状态

**Verification**

- 新增回归测试覆盖：
  - 部分选中后点击 `全选` 会变成全选
  - 全选后再次点击会全部取消
  - 文案显示 `全选（已选/总数）`
  - 无数据时禁用并显示 `全选（0/0）`
