# Backup UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make backup messaging and flow feedback clearly communicate the chosen `合并并覆盖` behavior without adding new backup modes.

**Architecture:** Keep the current backup pipeline intact, concentrate user-facing behavior changes inside the backup dialog, and use tests to lock down the new copy, success, cancel, and failure messaging.

**Tech Stack:** PyQt5, `views/backup_dialog.py`, `views/main_window.py`, `services/file_scanner.py`, `unittest`, `pytest`

---

### Task 1: Lock down the new backup copy in tests

**Files:**
- Modify: `tests/test_backup_dialog.py`

- [ ] Step 1: Add a test that selects a destination path and expects the status area to show both the target path and the `合并已有目录，覆盖同名文件` strategy text.

- [ ] Step 3: Add a test that verifies a successful backup shows `备份已完成（合并并覆盖）` in the status area and a matching information dialog message.
- [ ] Step 4: Add a test that verifies a cancelled backup shows `备份已取消，已保留已复制内容`.
